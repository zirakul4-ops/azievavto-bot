# Бот канала «Азиев Авто»

Каждый день публикует в Telegram-канал 5 новых автомобилей разных марок из каталога avexavto.ru:
примерно в 10:00, 12:30, 15:00, 17:30 и 20:00 по Уфе (GitHub может задерживать запуск на 5–20 минут).
В каждом посте: альбом до 5 фото, цена под ключ в Уфе, характеристики, разбивка цены и ваши контакты.
Одна и та же машина дважды не публикуется: номера лотов сохраняются в `posted.json`.

## Запуск (один раз, ~15 минут)

### 1. Создать бота
1. В Telegram откройте @BotFather → `/newbot`.
2. Имя: `Азиев Авто`, юзернейм: например `azievavto_post_bot`.
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохраните его, никому не показывайте.

### 2. Сделать бота администратором канала
Канал → Управление каналом → Администраторы → Добавить администратора → найдите бота →
оставьте право «Публикация сообщений» → Сохранить.

### 3. Загрузить бота на GitHub
1. Зарегистрируйтесь на github.com (бесплатно).
2. Справа вверху «+» → **New repository**. Название: `azievavto-bot`, выберите **Private** → Create repository.
3. На странице репозитория нажмите **uploading an existing file**.
4. Распакуйте архив и перетащите в окно браузера **всё содержимое папки** `azievavto-bot`
   (включая папку `.github`; на Mac она скрыта — нажмите Cmd+Shift+. в Finder, чтобы её увидеть).
5. Нажмите **Commit changes**.
6. Проверьте, что в репозитории есть путь `.github/workflows/post.yml`.

### 4. Добавить секреты
Settings → Secrets and variables → Actions → **New repository secret**:
- `TELEGRAM_BOT_TOKEN` — токен из шага 1;
- `TELEGRAM_CHANNEL` — адрес канала, например `@azievavto`.

### 5. Разрешить боту сохранять историю публикаций
Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.

### 6. Тестовый запуск
Вкладка **Actions** → слева «Публикация авто в Telegram» → **Run workflow**.
- С галочкой «Тестовый запуск» пост только покажется в логе (откройте запуск → post → Публикация).
- Без галочки — пост сразу уйдёт в канал.

Дальше всё работает само по расписанию.

## Настройки (необязательно)
Settings → Secrets and variables → Actions → вкладка **Variables** → New repository variable:
- `MAX_PRICE` — максимальная цена под ключ, например `3000000`;
- `MIN_PRICE` — минимальная цена;
- `MIN_YEAR` — не старше года, например `2021`;
- `BRANDS` — только эти марки через запятую, например `BMW,Audi,Volkswagen`.

## Как поменять время или количество постов
Файл `.github/workflows/post.yml`, строки `cron`. Время указано по UTC (Уфа = UTC+5):
`"57 4 * * *"` = 04:57 UTC ≈ 10:00 по Уфе. Одна строка = один пост в день.

## Если что-то пошло не так
- Вкладка Actions → красный запуск → откройте лог, там написана причина.
- «Проверьте TELEGRAM_BOT_TOKEN…» — неверный токен, адрес канала или бот не администратор.
- GitHub отключает расписание, если в репозитории 60 дней не было изменений. Бот сам
  сохраняет `posted.json` после каждой публикации, так что при нормальной работе этого не случится.
